# Mockup Prompt Helper (商業設計提示詞工具)

線上使用：https://chenchiaoyu.github.io/Mockup_Prompt_Helper/

Mockup Prompt Helper 是一套針對品牌設計師、電商視覺與包裝設計需求開發的提示詞建構工具。主要用於輔助生成商品展示（Mockup）圖像，透過標準化光學透視與物理尺寸參數，減少 AI 模型生成圖像時常見的形變與比例失調問題。

---

## 核心功能

### 1. 參考尺寸與比例控制
- 支援輸入長度、寬度、厚度（選填）與單位（cm, mm, m, inch）。
- 於提示詞中整合物理維度與工業比例約束語法，降低 AI 生成物件時的形變失真率。

### 2. 多元商業載體分類
- **日常與餐飲載體**：街頭圓形燈箱招牌、鐵捲門背景、熱炒啤酒杯、手搖飲封口杯、日式立旗等。
- **文創與周邊用品**：和紙膠帶、綁帶手帳本、壁掛月曆、手拿旗、三角掛旗、帆布托特包、陶瓷杯墊等。
- **商務與紙品印刷**：國際標準規格海報（A0–A4）、雙口袋提案資料夾、頂級壓凸名片、企業識別證等。
- **數位裝置與 3D 原型**：旗艦手機、平板、筆記型電腦、純白黏土模型（Clay）、零件拆解懸浮圖（Knolling）。

### 3. 光學原理與相機視角概念
- 於完整提示詞檢視視窗中提供光學原理結構圖解，涵蓋 CAD 三視圖、30° 軸測等角透視、90° 垂直俯視（Flat Lay）、0° 正視對稱、85mm 淺景深與微距特寫等。

### 4. 網路實物對照
- 每個載體與風格標籤均提供實物搜尋功能，可快速於 Google 檢索真實產品照片進行比對。

### 5. 色彩配置與表面紋理控制
- 支援品牌 Hex 色票輸入，並可指定主色調（Dominant）、點綴色（Accent）或環境氛圍（Atmospheric）。
- 提供多階段物理噪點與紙質紋理控制（從純淨商業棚拍至復古膠卷質感）。

### 6. 雙引擎輸出
- **Midjourney 引擎**：自動生成包含 `--ar`, `--s`, `--c`, `--no` 等參數格式的指令。
- **Universal 引擎**：轉換為適用於 Flux、DALL-E 3、Stable Diffusion 等模型的自然語言描述。

- **前端框架**：React 18, TypeScript 5
- **建置工具**：Vite 5

- **動畫庫**：Motion
- **圖示庫**：Lucide React
- **部屬平台**：GitHub Pages (經由 GitHub Actions 自動建置發布)
